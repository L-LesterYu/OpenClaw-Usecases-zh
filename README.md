# OpenClaw Usecases 中文版

本仓库收集了 OpenClaw 的中文用例，帮助用户快速部署和使用各种场景。

## 已支持的技能列表

| 场景名称 | 简短中文描述 | 文件路径 |
|---------|------------|---------|
| 办公自动化套件 | 将知识工作者日常重复性工作交给 OpenClaw 自动处理，包括邮件管理、文件整理、会议纪要、周报生成和日程同步等功能 | `usecases/cn-office-automation.md` |

## 如何使用

1. 阅读具体用例文档
2. 根据文档安装所需的技能
3. 按照文档配置和运行
4. 根据实际需求调整提示词和参数

## 如何贡献

欢迎贡献新的中文用例！请参考 `awesome-openclaw-usecases-temp` 中的源文件。

## 许可证

本项目遵循原 OpenClaw 项目的许可证。
